
# SQL Analytics Portfolio

Коллекция SQL-решений, демонстрирующих полный цикл работы с данными: от базового исследования и построения бизнес-метрик до оптимизации запросов, проектирования схем баз данных и управления транзакциями.

**Что изучено в рамках бассейна по SQL:**

* **Продвинутая аналитика**: расчет бизнес-метрик, группировка (`GROUP BY`, `HAVING`), когортный анализ.
* **Работа со сложными структурами**: многотабличные соединения (`INNER`, `LEFT`, `FULL`, `CROSS JOIN`), операции над множествами (`UNION`, `INTERSECT`, `EXCEPT`).
* **Проектирование БД (DDL)**: создание таблиц, настройка ограничений (`PRIMARY KEY`, `FOREIGN KEY`, `CHECK`), работа с представлениями (`VIEW`, `MATERIALIZED VIEW`).
* **Оптимизация производительности**: создание B-tree, составных, частичных и функциональных индексов, анализ планов выполнения запросов через `EXPLAIN ANALYZE`.
* **Продвинутые алгоритмы**: использование рекурсивных CTE (`WITH RECURSIVE`) для обхода графов и решения задачи коммивояжера (TSP).
* **Управление транзакциями**: понимание принципов ACID, работа с уровнями изоляции (`READ COMMITTED`, `REPEATABLE READ`), предотвращение аномалий (Non-repeatable read, Phantom read) и разрешение взаимных блокировок (Deadlock).

**Структура проекта**

Проект разбит на логические блоки — от базовых запросов к продвинутой аналитике и работе с СУБД.

**01–04: Базовые операции и аналитика**

* `01_sql_basics.sql` — фильтрация, сортировка, `CASE`, базовые подзапросы.
* `02_joins_and_set_operations.sql` — декартово произведение, `UNION`/`EXCEPT`, `NATURAL JOIN`, анти-джойны (`NOT IN`, `NOT EXISTS`).
* `03_joins_and_cte.sql` — типы `JOIN`, поиск пропусков через `generate_series`, самосоединения (self-join).
* `04_set_operations_and_dml.sql` — симметричная разница, модификация данных (`INSERT`, `UPDATE`, `DELETE`).

**05–07: Инженерия данных и производительность**

* `05_views_and_materialized_views.sql` — создание, обновление и удаление представлений и материализованных представлений.
* **`06_indexes_and_explain.sql`** — настройка индексов (составные, функциональные, частичные) и анализ планов выполнения запросов.
* `07_ddl_and_discounts.sql` — проектирование таблицы скидок, работа с последовательностями, бизнес-логика расчета скидок.

**08–11: Продвинутая агрегация, алгоритмы и транзакции**

* `08_group_by_and_having.sql` — расчет ключевых бизнес-метрик (LTV, средний чек, топ-N), фильтрация групп.
* `09_recursive_cte.sql` — базовый рекурсивный CTE для обхода графа.
* `10_recursive_cte_min_max_tour.sql` — поиск оптимальных маршрутов (min/max) в графе.
* `11_transactions_and_isolation.sql` — управление транзакциями, анализ уровней изоляции, обработка конкурентных обновлений и deadlock'ов.

**Скрины**

В папке `screenshots/` приложены практические доказательства выполнения запросов:

1. **Планы выполнения (`EXPLAIN ANALYZE`)** для файла `06_indexes_and_explain.sql`. Наглядно показано, как планировщик PostgreSQL использует:
   * `Index Only Scan` для частичных и составных индексов.
   * `Merge Join` для соединения таблиц.
   * Функциональные индексы (`upper(name)`) для поиска без учета регистра.
2. **Тесты транзакций** для файла `11_transactions_and_isolation.sql`, демонстрирующие:
   * Аномалии чтения (Non-repeatable read, Phantom read).
   * Возникновение и автоматическое разрешение взаимных блокировок (Deadlock detected).

**Запуск**

Все запросы написаны для **PostgreSQL**. Для запуска скопируйте содержимое нужного файла в ваш SQL-клиент (DBeaver, DataGrip, pgAdmin) и выполните.
*Для файла `11_transactions_and_isolation.sql` требуется два параллельных подключения (сессии) к базе данных, чтобы воспроизвести сценарии с конкурентным доступом.*
